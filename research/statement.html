PROPOSED DOCTORAL RESEARCH / DISCUSSION DRAFT

Reliable multimodal emotion recognition under resource constraints

Learn within a budget. Decide with evidence. Update without losing reliability.

A proposed study of audio, text and video when labels are scarce, inputs degrade and emotion classes expand. Engineering experience supports the interaction prototype; the methods below remain to be evaluated.

01

Four questions, with evidence to test

Open a question to inspect its controls, measures and planned outputs.

01Budget-aware adaptationDoes richer fusion earn its cost?+

Compare frozen-feature linear / MLP baselines, lightweight adapters and interaction fusion under a shared total label budget.

Controls
Share splits, sample indices, seeds and tuning trials; audit near duplicates and background cues. Log class-wise recall and prediction proportions.
Decision evidence
Macro-F1, UAR and cost across paired repeats. A gain should survive budget controls and artifact audits.
Planned outputs
Budget ledger, shared feature cache and baseline protocol.
02Evidence-aware decisionsWhen should the model request review?+

Gate fusion with quality and missing-input masks; combine calibrated confidence with cross-modal disagreement for selective prediction.

Controls
Apply missing-modality, noise, occlusion and transcript perturbations. Ablate quality, disagreement and calibration separately. Choose thresholds on development data.
Decision evidence
Compare risk at the same coverage, or coverage at the same risk; report calibration error (ECE). All inputs missing leads to insufficient evidence.
Planned outputs
Fusion module, calibration configuration and review rule.
03Continual adaptationCan new classes preserve earlier decisions?+

Compare sequential fine-tuning, parameter constraints and prompt / adapter updates with bounded replay and recalibration.

Controls
Repeat predefined class orders without a task ID at test time. Compare retaining old thresholds with recalibration. Check candidates on development data.
Decision evidence
New / old class performance, forgetting, calibration drift and risk–coverage changes, alongside update time and storage.
Planned outputs
Update records and version bundles: weights, preprocessing, labels, class descriptions and calibration.
04Integrated validationDo the methods work together under failure?+

Integrate modality status, prediction review and version comparison into an interaction prototype. Evaluate the three research strands together.

Controls
Repeat controlled studies; report datasets separately. Check missing inputs, interface errors, timeouts, switching and rollback at fixed hardware and input conditions.
Decision evidence
Conclusion stability, end-to-end latency, review triggers and whole-version rollback consistency. Independent tests follow protocol freeze.
Planned outputs
Reproducible code, per-sample predictions, failure cases and prototype verification records.

Studies 1–3 build on one another. Study 4 tests the shared chain throughout, rather than only after implementation.

03

How the claims would be tested

One label budget

Count distinct labeled examples used for training, selection and calibration; count new labels cumulatively. Keep independent evaluation separate.

Controlled data

Start with MELD and authorized IEMOCAP access. Audit sessions and near duplicates; report official and additional grouped splits separately.

Comparable evidence

Save per-sample probabilities, labels, groups and versions. Use paired repeats and session-grouped uncertainty estimates.

A frozen final test

Development data select candidates and thresholds. Independent tests evaluate the frozen protocol; simpler methods remain valid outcomes if complex ones do not help.

Read the public protocol checklist on GitHub ↗
Task scope and later extensions

The core task predicts observable dataset emotion labels; it does not infer an unobserved mental state. A request for review limits automatic output and does not establish the effectiveness of human review.

Open-vocabulary recognition and unknown-class detection are separate, later protocols. Education is a potential application requiring its own data and outcome study.

# 首页前端评审与改进 / Homepage frontend review

本记录对应 2026-10-27 的一次首页检查。重点是访客能否找到项目、读清内容并完成操作。

## 发现与修复

| 实测问题 | 修改 |
| --- | --- |
| 搜索隐藏项目后，跳转到该项目锚点仍可能不可见 | 点击、直接 URL、重复锚点与 hashchange 统一展开目标；清除不兼容的搜索及分类条件 |
| 手机菜单点击页面外部不收起 | 补充外部点击、焦点离开和切换到桌面宽度后的关闭行为；Escape 恢复按钮焦点 |
| 手机首屏的主要操作入口较晚出现 | 将在线 Demo、项目代码和学术简历入口前置，压缩重复能力说明 |
| 首次阅读即展开所有项目，页面很长 | 默认展示 6 个代表项目，可展开全部 12 个；搜索和分类始终覆盖全部项目 |
| 学习区两个链接紧邻，查找笔记还需再次导航 | 分行展示入口，增加使用 GET 参数的笔记搜索，直接进入搜索结果 |
| 浅色主题中部分橙、青绿及红色小字对比度不足 | 加深状态与说明文字颜色，复查浅色和深色主题 |
| 多张 PNG/JPEG 展示图和视频封面较大 | 生成 WebP 展示版本，补齐展示图宽高；原始大图的预览入口继续可用 |

## 实际验证范围

- **26 项 Node / JSDOM 检查通过**：10 项新增项目导航及折叠回归，16 项既有轮播、阅读设置和减少动态效果回归。
- **33 项浏览器检查通过**：项目筛选、锚点、键盘操作、图片弹窗、视频标签、笔记搜索、语言切换、菜单与无 JavaScript 阅读。
- 中英文在 **320、390、768、1024、1440 px** 宽度下检查，未发现页面横向溢出。
- 另行检查普通动画模式的轮播自动播放/暂停、主题/语言过渡，以及共享脚本在笔记和案例子页中的运行。
- axe-core **4.10.3**，WCAG 2 A/AA 与 2.1 AA 规则；展开全部项目后，浅色、深色扫描均无自动检测违规。色彩检测使用减少动态效果模式，以免把过渡帧颜色当作稳定页面颜色。
- 自动检测不能替代所有辅助技术和真实设备测试；本轮没有声称完成跨浏览器兼容认证或屏幕阅读器人工验收。

## 体积与阅读长度

12 张展示图及视频封面由 **948,218 字节**变为 **460,962 字节**，减少 **51.4%**。这是静态媒体体积比较，不等同于加载速度提升 51.4%。

在本轮 390 px 中文浏览器视口中，默认页面高度约由 **24,403 px**减为 **19,100 px**；主要演示入口顶部约位于 **410 px**。页面长度随字体、语言和展开状态变化，这些是检查环境的观测值。

## 后续维护

1. 新增项目时保留稳定的锚点 ID，更新默认项目选择，检查搜索后跳转与重复点击同一锚点。
2. 替换截图时同时更新展示尺寸；全尺寸证据图与压缩展示图应来自同一内容。
3. 修改 `academic.js` 后检查首页与笔记、案例子页，避免共享脚本依赖首页专属控件。
4. 无 JavaScript 时保留所有项目、原生视频控件和可打开的目录；增强控件仅在脚本可用后显示。

The release improves navigation reliability, reading hierarchy, contrast and media size. It preserves the research statuses, project descriptions, twelve project entries and nineteen learning notes. This document records a bounded browser review, not a claim of complete accessibility or real-user performance validation.

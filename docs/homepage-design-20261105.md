# 首页工程项目阅读入口调整 · 2026-11-05

这次更新缩短了个人介绍到工程案例的阅读路径。首屏提供三个手动切换的项目预览：禾镜图像检测、辅导员协作与发布验证、配置驱动表单。每项预览包含具体功能、案例或演示入口，以及当前公开内容的范围说明。

## 页面调整

- 主操作统一为“查看工程案例”和“动手体验项目”；公开简历、研究和笔记作为辅助入口。
- 默认展示禾镜、辅导员协作和低代码表单，其余项目仍可通过分类、搜索和展开全部访问。
- 近期更新改为可展开区域，放在代表项目之后；禾镜版本说明统一为 v1.7，主入口直达免登录演示中心。
- 统一首屏标题、中文字体、段落间距和蓝绿强调色，并提供深色主题。
- 保留 15 个项目、40 篇学习笔记、既有链接、研究状态及内容边界。

## 交互与兼容

首屏切换不自动播放。Tab 进入已选标签，左右方向键及 Home / End 切换预览；继续 Tab 可进入当前预览的链接。动画遵循系统及站内的减少动态设置。未启用 JavaScript 时，三个项目摘要按顺序展示。

使用桌面 Edge 的无头浏览器检查了中英文及 320、390、768、1024、1440、1920 像素视口，覆盖预览切换、搜索与空状态、分类、展开全部、浏览器返回、旧项目锚点、笔记搜索、演示分类、浮动短片、手机菜单及减少动态设置。首屏抽查的 18 组浅色/深色文字与背景对比度均不低于 4.5:1。此记录不等同于真实移动设备或所有浏览器的兼容性认证。

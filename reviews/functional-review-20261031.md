## 已修复的问题

| 问题与复现方式 | 修复后的行为 |
| --- | --- |
| 搜索 KICP 或选择工程分类后刷新，列表恢复为默认三项 | 搜索、分类和展开状态写入 URL；刷新、分享及浏览器前进／返回能恢复。直接打开具体项目仍优先显示目标，并清除冲突筛选 |
| 选择首页的工程笔记分类后刷新，回到“最新三篇” | 笔记分类保存在 `notes` 参数中，支持刷新与浏览器返回；正文与既有笔记不变 |
| 从虚拟主播切到另一段视频，地址仍为 `#film-host` | 鼠标和键盘切换同步视频锚点；刷新和返回恢复对应视频，切换时暂停上一段播放 |
| 完整截图请求失败后只显示破图，无法恢复 | 显示加载状态、失败说明、重试按钮和原图入口；旧预览的迟到响应不能改变新截图；关闭后焦点返回打开按钮 |
| 中文界面的截图说明仍是英文 | 共享语言逻辑处理图片替代文本；为首页 16 张既有展示图片补齐双语描述，并同步预览说明 |
| Tab 离开阅读设置后，面板仍浮在页面上 | 焦点离开设置区域即收起；在区域内部切换控件不会误关闭，Escape 仍返回设置按钮 |
| 点击返回顶部后，键盘焦点落到 body | 滚动到顶部时将焦点移到正文起点，继续按 Tab 可从页面内容开始浏览 |
| 研究计划页打印后所有问题保持展开；重复打印事件也会覆盖原状态 | 由共享脚本统一管理打印快照，移除研究页的重复监听；打印展开证据，结束后恢复原来的折叠和筛选状态 |

## 链接与筛选设计

首页筛选使用独立参数，保留现有版本查询参数和章节锚点：

- `?project=engineering#work`：工程分类。
- `?project-q=KICP#work`：项目关键词。
- `?projects=all#work`：展开全部项目。
- `?notes=engineering#notebook`：工程心得分类。

输入关键词使用 `replaceState`，避免每次输入都增加浏览历史；分类和展开操作使用 `pushState`，允许返回上一次选择。无需登录或保存个人数据。

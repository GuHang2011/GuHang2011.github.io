# 首页视觉改版 · 2026-10-30

这次修改主要解决原首页的视觉问题：文字层级接近、项目截图偏小、细边框较多，以及各板块缺少明确的视觉节奏。

| 问题 | 设计调整 |
| --- | --- |
| 首屏像资料目录，难以直观看到工程工作 | 用大字号姓名、简短介绍和真实项目界面组成首屏；在线演示、项目和简历作为主要入口 |
| 各部分颜色和结构过于接近 | 暖白底色配深蓝文字、少量锈橙标记；演示区使用深蓝底，研究区使用白底 |
| 项目图片太小或长图占用过多空间 | 社区项目采用左右分栏的封面卡，辅导员与表单项目采用双列大图卡；封面可打开完整原图 |
| 笔记和研究信息缺少阅读层次 | 研究按年份、状态和标题排列；笔记使用一张导读卡与文章列表，保留分类和搜索 |
| 个人经历与工程内容争抢首屏空间 | 教育背景与工作经历集中展示，简历入口仍在首屏 |
| 动效缺少重点 | 首屏短暂进入、截图悬停和演示卡反馈；尊重系统及手动减少动态设置 |
| 小屏辅助文字与暗色悬停状态不够清晰 | 调整项目正文、链接和标签字号；修复锈橙文字、卡片编号、联系区标签以及暗色按钮悬停的对比度 |

## 图片来源与加载

首屏与社区项目封面来自既有的 `assets/shuyang-home/desktop-home.png`。裁取顶部界面并压缩为 `assets/optimized/shuyang-portfolio-cover.webp`，尺寸 1200×750，大小 47,700 字节。完整原图保留在截图预览中，未改变项目内容或验收结论。其他项目图片使用既有素材；没有引入远程字体或新的运行时依赖。

## 验证范围

- 34 项交互与布局断言通过，覆盖搜索、筛选、隐藏项目定位、研究深链接、轮播、视频暂停、打印状态恢复、手机菜单和无 JavaScript 阅读。
- 中英文分别检查 320、390、768、1280、1440 像素宽度，未出现页面横向溢出。
- 明亮／深色主题在 390、1440 像素宽度执行 axe WCAG 2 A/AA 与 2.1 AA 扫描，均无报告项；另外检查展开后的八个演示和主按钮悬停状态。
- 人工查看桌面、手机、中英文、明暗主题的页面截图；确认封面能打开完整原图，手动减少动态可关闭新加入的进入动画与旋转效果。

自动扫描不能替代完整的人工无障碍评估。浏览器验证使用桌面 Edge 及模拟视口，未代表真实手机设备验收。本次没有重新执行各业务项目的完整测试。

保留 13 个项目、8 个演示、4 段视频与 26 篇笔记入口。Climate Risk Management 和 Neurocomputing 仍标注“已投稿，尚未录用”；本次视觉改版不新增研究结果或录用声明。

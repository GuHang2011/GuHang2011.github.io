# 首页设计调整 · 2026-11-09

这次修改针对首屏的文字层级、手机端留白和项目入口。主页以工程蓝为主色，项目目录、研究目录和笔记页面沿用同一组颜色。

## 参考与取舍

- [IBM Design Language](https://www.ibm.com/design/language/)：参考栅格、文字对齐与内容层级。
- [Microsoft Fluent 2](https://fluent2.microsoft.design/)：参考主次区域、按钮状态和克制的交互。
- [React](https://react.dev/)：参考文字与可见示例并排的组织方式。

参考页面的布局原则，使用本站现有的项目截图。没有复制品牌素材。

## 具体修改

1. 浏览进度改为导航下方的 2px 细线，保留辅助技术可读的当前章节和百分比。
2. 去掉首屏重复的姓名眉题。手机端标题为 28px、正文为 17px，缩短自我介绍，让项目预览更早出现。
3. 新增三个手动切换的项目预览：禾镜巡检、校园协作、配置化表单。支持鼠标、键盘方向键及 Home / End 键。
4. 宽屏使用左右分栏首屏、三列代表项目。窄屏按阅读顺序纵向排列。
5. 流式交互与 MeteoFormer 演示单列为“可以直接试用”，让读者更容易找到实际操作入口。
6. 页面以白色、深蓝文字和浅蓝背景划分层次；少量暖色用于次要标记。切换动画遵循减少动态效果设置。

## 检查范围

主页检查中英文、明暗主题及 320 / 390 / 768 / 1024 / 1440px 宽度，覆盖菜单、预览切换、截图放大、学习时间轴和无 JavaScript 时的入口。另抽查项目目录、研究目录、笔记目录及 Agent 教程的排版与颜色对比度。

这次没有重新验收各演示系统内部的全部业务流程。论文状态、项目来源、合成数据说明和现有学习笔记内容沿用原有记录。

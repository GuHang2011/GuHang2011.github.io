# 首页阅读体验复查 · 2026-10-30

这次复查按“第一次访问的导师或工程同行，能否迅速找到具体工作并继续核对”来调整页面。范围为首页的信息组织、交互与显示，不重新验收各业务系统，也不更新论文投稿结论。

## 问题与修改

| 观察到的问题 | 本次修改 | 核查方式 |
| --- | --- | --- |
| 首屏偏技术名词罗列，演示主按钮只跳到页面下方 | 改为直接说明界面与工作流能力；主按钮直接进入 React 演示，另设项目、简历、研究状态和博士研究设想入口 | 点击和中英文页面检查 |
| “精选项目”默认显示 7 项，重点不突出 | 默认呈现社区系统、辅导员协作、低代码表单三个入口，补充试点／案例／原型的材料类型 | 核对完整目录仍有 13 项，搜索和展开可达 |
| 默认页面过长，图解、项目和研究解读重复占用阅读空间 | 工程项目和可操作演示前置；工作亮点、工程图解、补充演示、视频与研究阅读指南按需展开；笔记默认预览最新三篇 | 对比同尺寸默认页面，检查旧锚点仍自动展开 |
| 演示需要读者自己猜应该试什么 | 生产报工、电信订单、React 工作流各提供一个可操作的异常处理任务，并注明合成数据／模拟故障 | 对照各演示现有 README，检查跳转 |
| 研究筛选为“会议”后，跳到稿件锚点仍隐藏目标 | 跳转到隐藏稿件时恢复全部研究筛选 | 重现旧行为并验证修复 |
| 移动菜单跳转后缺少明确的键盘阅读落点 | 锚点目标获得焦点；固定导航上方留出滚动间距 | 手机菜单跳转与焦点检查 |
| 首页直接打印会输出较长作品集；筛选状态还可能漏掉条目 | 首屏打印入口指向独立简历；浏览器打印首页时暂时显示全部项目与笔记，打印后恢复 | beforeprint / afterprint 状态检查；简历页面冒烟检查 |
| 自动轮播会打断阅读 | 默认手动切换，保留自愿开启播放、键盘切换和减少动态设置；视频区域收起时暂停播放 | 普通／减少动态模式、轮播和实际视频暂停检查 |
| 长页末尾缺少直接联系入口 | 增加邮件与简历链接 | 链接及布局检查 |

## 本次验证

- 34 项交互与布局断言通过，包含项目展开、搜索、研究筛选后跳转、嵌套区块深链接、轮播、视频暂停、打印恢复和无 JavaScript 阅读。
- 中英文分别检查 320、390、768、1280、1440 像素宽度，未出现横向溢出。
- 明亮／深色主题分别在 390、1440 像素宽度执行 axe WCAG 2 A/AA 与 2.1 AA 规则扫描，四次扫描未报告违规。自动扫描不等于完整人工无障碍认证。
- 普通动态模式下手动轮播可用；在线简历、AI 学习感悟、React 工作流三个共用脚本页面完成加载与语言切换冒烟检查，未捕获 JavaScript 异常。
- 对比中文、减少动态、默认未展开状态：1440×1000 下页面高度从 12,553 降至 7,666 像素；390×844 下从 21,766 降至 11,665 像素。该指标说明默认阅读长度变化，不代表加载速度或 Core Web Vitals。

保留全部 13 个项目、8 个交互演示、4 段视频与 26 篇笔记入口。文章、简历记录及论文作者／投稿状态保持原有依据。

# 在线演示界面统一 · 2026-11-01

本轮覆盖 `/demos/` 目录和十个既有交互演示。配色参照用户提供的学院工作任务截图：深藏蓝 `#11213b`、亮蓝 `#205ad3`、浅灰 `#f5f7fa`、白色内容区域；导航、按钮、筛选表单、表格边界和焦点提示保持一致。参考 Element 官网的设计原则：一致性、反馈、效率和可控。

## 实际框架与范围

| 页面 | 实现 |
| --- | --- |
| 虚拟主播 | Vue 3.5.44 + Element Plus 2.14.7，Button、Card、Tag、Select、Switch、Alert |
| React 工作流 | React 18.3.1 + Ant Design 6.6.8，ConfigProvider、Button、Select、Card、Tag、Alert |
| 其他八个实验 | 共用样式 `demos/element-theme.css` 与导航 `demos/demo-navigation.js`；原计算、表单校验和状态实现继续保留 |

不是将所有演示迁移成同一个框架。React 的 reducer、低代码配置校验和各分析模块仍能独立阅读、测试。新增依赖锁定版本、本地打包，运行不依赖第三方 CDN。Element 与 Ant Design 的运行依赖许可随包保存。

公开实验使用合成数据，无真实登录和后端授权；学院系统在公开站点保留案例、学院名称和脱敏截图。本轮未更改本地学院系统，也未添加伪装成生产认证的登录页面。

## 检查发现与修复

| 问题 | 处理 |
| --- | --- |
| 各演示颜色、按钮与面板样式分散 | 统一设计变量、导航色、表格表头、筛选区、边框、圆角与焦点样式 |
| 缺少返回完整演示列表的明确入口 | 统一作品首页 / 全部演示 / 当前项目的导航层级 |
| 目录只列八个项目 | 补入 BLEU 与可靠性门禁，十个现有演示都可从目录进入 |
| 主播手机端不容易找到播放按钮 | 播放控制前置；章节、角色和偏好分组；新增语速与双语字幕开关 |
| 播放视频与主播讲解可能同时发声 | 两类媒体播放互斥，启动一个会暂停另一个 |
| React 自定义控件外观不统一 | 接入真实 Ant Design 控件，保留状态、版本和异步保护 |
| 原样式覆盖 Ant Design 的透明输入层 | 单独约束框架输入层，恢复选择器当前值显示 |
| Ant Design 下拉列表缺少独立可访问名称 | 为列表补充名称；少量选项关闭虚拟化；跟随系统减少动作偏好禁用框架动画 |
| 小字与表格序号对比度不足 | 加深辅助文字、步骤编号和表格序号，保留状态语义颜色 |

## 验证

- 两个框架的生产构建通过；React 原有 8 项状态测试通过。
- 11 个页面在 320、390、768、1440、1920px 下共 55 次宽度检查无页面溢出；没有破图或页面脚本异常。
- 11 个页面的 axe WCAG A/AA 自动扫描未发现违规。Chart.js 在视口变化后有异步尺寸更新，宽度断言等待其布局稳定后执行。
- 虚拟主播 35 项检查通过：实际画布动画、暂停、双角色、六章定位、故障重试、录制画幅、语速、字幕、键盘与媒体互斥。
- Ant Design 工作流 14 项检查通过：角色选择、网络失败重试、冲突刷新、请求中重置、中英文、手机导航、减少动作下的下拉操作与无障碍扫描。
- 生产报工与电信办理的既有回归通过 34 项交互检查、16 次中英文视口检查与 3 次无障碍扫描；数量校验、重复提交保护、冲突恢复和重置行为保留。
- 两个新增框架项目的生产依赖审计返回 0 个已知漏洞；这不等于依赖永远无风险。

浏览器脚本见 `reviews/checks/element-demos.js`、`element-presenter.js`、`antd-workflow.js`。自动扫描和模拟视口不替代真实设备与辅助技术验收。

101 秒主播展示片和 60 秒操作片继续保留先前暖色界面版本，页面已标注；交互版包含本轮新增控制。模型、配音及视频时长没有改动。

## 复现

先分别在 `demos/react-workflow/` 与 `demos/virtual-host/ui/` 运行 `npm ci`、`npm run build`；再从网站根目录运行 `python tools/serve_presenter.py`。本机预览为 `http://127.0.0.1:8778/`，支持长音频 Range 请求。无需安装依赖也可直接访问已发布的静态产物。

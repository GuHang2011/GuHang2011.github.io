# 首页字体与布局复核

2026-11-01。范围为首页，包括项目、研究、笔记、经历及悬浮视频入口。

## 问题与修改

| 发现的问题 | 本次修改 |
| --- | --- |
| 多轮改版后标题混用衬线和无衬线字体，小屏说明与链接偏小 | 统一主要标题的中文无衬线字体栈。主要正文 15px，经历说明 14px，辅助说明 13px；章节标签保留较小字号。Windows 实际渲染字体已检查为 Microsoft YaHei。 |
| 米白底、深色联系横幅与新蓝白模块不协调 | 统一淡灰蓝画布、深蓝文字和蓝色操作入口；联系区改为浅蓝底，随阅读主题切换。 |
| 首屏斜放截图、项目装饰编号和卡片层级分散注意力 | 首屏截图平直排列；隐藏装饰编号，明确项目标题、说明、证据备注与操作链接的层级。 |
| 章节跳转重复计算顶部间距 | 统一由页面滚动留白处理，跳转后内容位于固定导航下方约 16px。 |
| 手机教育和技能列表拥挤，笔记标题断行不自然 | 教育、技能列表改为单列；笔记主标题按完整语义分行，搜索输入保持 16px。 |
| 原项目展开提示保留旧数量 | 使用与数量无关的介绍文案，按钮实际数量继续由现有脚本计算。 |
| 悬浮入口体积大，遮挡正文 | 桌面改为轻量入口，手机保留视频图标和关闭按钮；收起状态与返回顶部并排靠底。展开窗口继续支持选择、收起、关闭和键盘操作。 |
| 极窄屏隐藏姓名后，品牌链接缺少可访问名称 | 为返回首页链接补充中英文名称，同时保留键盘焦点提示。 |

## 验证

- 46 项检查通过：项目搜索、分类、展开和收起，笔记搜索与分类，研究概要，章节跳转，截图预览及焦点恢复，手机导航、阅读设置、亮点键盘切换、视频窗口等。
- 中英文 × 明暗主题 × 320 / 390 / 768 / 1024 / 1440 / 1920px，共 24 组布局检查；包含展开的辅助内容和全部项目，没有页面或所检查容器的横向溢出。
- 14 次 axe WCAG A/AA 自动扫描无违规，包括 320 / 390 / 1440px 的展开页面及手机播放器状态。
- 检查了桌面、手机和深色截图；720px 下增加字距、词距、行距和段间距后无页面横向溢出。这是浏览器视口与重排检查，不等同于完整真实设备或所有浏览器的缩放测试。
- 主要标题、正文和控件的计算样式已核对，测试过程无 JavaScript 异常。

检查脚本：[`checks/ui-audit.js`](checks/ui-audit.js)。本地预览使用 `http://127.0.0.1:8778`，通过 Playwright CLI 的 `run-code --filename` 执行；axe 使用既有 `output/frontend-audit/node_modules/axe-core/axe.min.js`。

本次调整集中在首页设计与可读性。项目、研究成果、笔记正文和论文投稿状态保持原有事实；未新增实验结果或项目指标。自动扫描不能替代所有真实设备与读屏器测试。

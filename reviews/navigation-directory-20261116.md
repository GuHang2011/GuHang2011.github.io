# 导航与演示目录检查 · 2026-11-16

本次检查覆盖个人首页、项目目录、截图图集、学习笔记及演示目录。工程蓝色和主要排版保留，修改集中在能复现的问题。

## 问题与修改

| 问题 | 触发方式 | 修改后 |
| --- | --- | --- |
| 项目筛选在刷新后消失 | 先打开 `projects.html#project-fieldlens`，再选研究类或搜索 KAPT，然后刷新 | 新筛选排除锚点项目时，清除冲突锚点；查询和分类仍能恢复。直接访问项目锚点时仍揭示目标。 |
| 手机菜单跳过导航链接 | 在小屏用键盘打开菜单，再按 Tab | 打开时进入第一条导航，继续 Tab 可逐项访问；Escape 返回菜单按钮，关闭后不把焦点留在隐藏链接中。 |
| 演示目录与已有内容不同步 | 从项目页进入“全部 10 个演示” | 入口改为“演示目录”，目录补入已有气象工作台和流式回答实验，继续保留原有演示。 |
| 目录仍显示旧图与概念图 | 对比项目目录、截图图集与演示目录 | 目录统一引用已有界面实拍，写明原拍摄日期；每项仍区分合成数据、固定回答和需要本地部署的能力。 |
| 目录说明偏小，截图被裁切 | 在手机与桌面查看项目卡片 | 正文提高至 16px、截图说明 14px；预览按原始比例完整显示，按钮增加可点击高度。 |
| 目录返回与研究入口不准确 | 点击目录中的研究导航或“返回主页” | 研究入口指向当前研究页，返回链接定位到首页的在线体验栏目。 |

共享导航脚本的引用版本一并更新，避免旧缓存继续显示已修复的交互。笔记正文、论文状态和截图拍摄日期未因此改写。

# 首页在线体验模块改版

更新：2026-11-01。范围为首页 `#demos`，演示应用的业务逻辑不变。

## 改了什么

- 默认浅灰背景、白色卡片和蓝色操作按钮，跟随全站深色阅读偏好。
- 中文标题和正文使用同一无衬线字体栈；简介为 15px、1.85 倍行高，标题为 21–22px，主按钮至少 44px 高。
- 三个精选项目：生产报工、React 工作流、虚拟主播。按工程交互、数据与模型、虚拟主播切换，可发现全部十个演示。
- 十张截图重新取自当前公开演示代码，压缩为 WebP。预览完整保留画面比例，避免把表单或工作流边缘裁掉。
- 每张卡片提供简介、三步操作提示、在线入口和源码说明；保留模型早停回放与四段项目短片。
- 阅读该模块时，未打开的悬浮放映入口让出空间，可用标题旁“观看短片”打开原播放器。
- 修正页面滚动内边距与章节滚动外边距重复叠加造成的锚点空白。

## 内容边界

这些是使用合成数据的公开工程学习原型。故障、订单冲突和门禁阈值用于展示交互逻辑；页面不把演示描述为真实生产系统、实测科研结果或新完成的研究成果。主播截图展示 Live2D 官方示例 Mao，原项目保留素材说明。视频保留原文件，不在本轮重新录制。

## 验证

- 44 项功能检查通过：分类、键盘、焦点恢复、旧锚点、十一条页面入口、无 JavaScript 降级、图片与字号。
- 中英文 × 四种筛选 × 五种宽度（320 / 390 / 768 / 1440 / 1920）：40 次布局检查，无横向溢出。
- 亮色 / 深色 × 中英文 × 四种筛选：16 次 axe WCAG A/AA 自动扫描，无违规。
- 正常动画、视频折叠、视频切换和锚点定位四项补充检查通过；视频展开后的 axe 检查无违规。
- 已人工检查桌面、深色和手机截图。自动扫描无法替代所有读屏器和真实设备测试。

复核脚本：`reviews/checks/demo-gallery.js`。使用已有 Playwright CLI 会话，预览地址 `http://127.0.0.1:8778`；axe 路径沿用 `output/frontend-audit/node_modules/axe-core/axe.min.js`。脚本返回结构化结果并输出布局截图。

## 实现

`demo-gallery.css` 和 `demo-gallery.js` 作用于首页体验区。筛选使用普通按钮与 `aria-pressed`；数量变化通过状态区域播报，保留按钮焦点。禁用 JavaScript 时十张卡片全部可读，筛选控件保持隐藏。动效遵循系统和站内的减少动态效果偏好。

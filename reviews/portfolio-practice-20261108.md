# 主页返工记录与流式回答实验：验证范围

更新日期：2026-11-08。两篇新增笔记、一个 React + Ant Design 学习演示，以及首页和目录入口。没有模型服务调用。

## 核心验证

在 `demos/ai-stream` 执行 `npm test`，10 项测试通过。覆盖正常分段与完成、等待及输出期间重复开始、首段前停止、停止后迟到失败、重置后迟到文字、失败重试、迟到完成、非法重试、离开清理与计时器取消。

测试使用可控制的异步源，故意忽略 AbortSignal，验证请求归属检查仍能保护新状态。`npm run build` 通过 TypeScript 严格检查并生成线上 bundle。

## 浏览器复查

本机 Microsoft Edge 自动化检查实际构建产物，范围包括：

- 正常输出、停止并保留部分文字、重新生成至完成。
- 慢速场景在首段之前停止，等待原延迟结束后没有旧文字回写。
- 中途断开后保留文字；恢复连接并重试时从头开始，模式同步为正常。
- 输出中清空，切换话题，上一轮不混入新内容。
- 键盘开始与停止、复制操作反馈、状态播报方式。
- 演示在 320、390、768、1024、1440 像素宽度下无横向溢出。
- 首页、项目目录、笔记目录和两篇文章在中文、英文及 320、390、1440 像素下复查。
- 目录保留已有记录，更新为 45 篇笔记、16 个项目和 7 条学习时间轴记录；新文章可检索，新演示可从首页进入。

发现并修复：系统启用减少动态效果时，纯 CSS 禁用动画使 Ant Design Select 停留在 `scale(0)`。将系统偏好传递给 ConfigProvider 的 `motion` token 后重新检查下拉选择；状态指示动画也遵从该偏好。

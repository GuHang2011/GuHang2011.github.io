# 表单、重试与文章目录检查 · 2026-11-18

这一轮沿着实际使用路径检查：首页预览与阅读设置、低代码字段编辑、流式回答恢复，以及笔记目录与文章定位。

## 发现的问题与修改

| 问题 | 怎样出现 | 修改后的行为 |
| --- | --- | --- |
| 编辑字段标题后，焦点回到原输入框 | 修改低代码表单的字段标题，再按 Tab 或点击必填选项 | 提交标题时保留编辑器节点；Tab、Shift+Tab 与鼠标点击继续按原顺序操作，预览同步更新。 |
| 切换语言丢失 JSON 草稿 | 在配置编辑区输入尚未应用的 JSON，再切换中英文 | 保留草稿原文，包括未完成的 JSON；应用和重置仍由用户主动触发。 |
| 重试回答与所选话题不一致 | 停止输出，切换话题，再点重新生成 | 重试继续使用上一次请求的话题，同时同步话题选择器与正常连接状态；新话题使用“开始演示”。界面与项目说明都解释这一区别。 |
| 文章目录提前高亮下一节 | 当前段落仍在固定页头下方，下一段进入视口 | 根据段落相对阅读位置的坐标确定高亮；正反向滚动、语言重排和锚点跳转都更新定位。 |

首页的项目预览键盘切换、深色模式、截图打开与焦点返回、页底 100% 进度显示，在中英文和 390 / 1440px 下检查正常。笔记目录的搜索、主题筛选、分批展开和空状态恢复也通过了本次检查。

# 悬浮项目放映室

首页右下角增加一个可收起的项目视频窗口。读者可以边看工程介绍，边打开对应演示；关闭窗口后，仍可从首页介绍区的「悬浮看演示」入口重新打开。

## 四段现有短片

| 内容 | 展示范围 | 进一步阅读 |
| --- | --- | --- |
| 虚拟主播 | 卡通动画、合成中文配音、中英字幕 | [在线操作](../demos/virtual-host/) |
| 主播操作流程 | 章节切换、暂停与重播的无声回放，使用合成内容 | [实现说明](../demos/virtual-host/README.md) |
| 模型早停动画 | 使用合成数值讲解检查点与耐心计数，非真实训练记录 | [调节参数](../cases/kapt/#early-stopping) |
| 数据处理动画 | 虚构记录的校验、去重、隔离与汇总核对 | [在线操作](../demos/data-preparation/) |

视频、封面和字幕复用原页面的视频目录。此次增加观看入口与交互，没有新增模型推理结果或研究实验。

## 交互设计

- 默认只有小入口；展开前不创建视频，点击播放前不请求 MP4。
- 上一段、下一段和项目选择框均可切换。切换后等待用户播放。
- 收起即暂停，重新展开保留进度；× 在当前标签页会话中隐藏播放器。
- 与页面视频区共用单一播放权，避免两个视频同时发声。隐藏标签页、离开页面或打印时暂停。
- 沿用首页深蓝与暖白配色，适配深色阅读模式。展开有短暂动效，尊重减少动态偏好。
- 原生视频控件保留字幕、进度和全屏入口。页面语言切换时选择对应字幕；之后可在原生字幕菜单自行调整。
- 失败时显示重新加载与视频文件入口。手机横屏使用内部滚动，底部操作保持可达。
- 禁用 JavaScript 时隐藏不可用的悬浮入口，保留原页面视频区。

## 验证

在 Windows Edge 中通过 [55 项悬浮播放器断言](checks/floating-player.js)，包括四段视频实际解码和播放、中英字幕、收起和恢复、失败重试、页面内视频联动、打印、会话隐藏以及无 JavaScript 回退。覆盖 320×568、390×844、768×1024、1440×1000 和 844×390 五种视口。亮色与深色窗口的 axe 4.10.3 扫描未发现所选 WCAG A/AA 规则违规。

开发中发现并修复了两项问题：浏览器默认字幕选择与页面语言冲突；浮窗类名与原视频区重名。回归明确检查只有一个字幕轨显示、原视频区保持正常文档流。

另复跑首页原有的筛选、预览、导航、打印和布局回归。标签页隐藏与打印生命周期通过浏览器事件模拟检查；视口模拟不等同于真机验收，axe 扫描也不替代人工无障碍评估。

复跑方式见 [检查说明](checks/README.md)。

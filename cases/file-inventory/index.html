Exclusions and error records

Avoid mixed groups

A real directory named (root files) used to collide with the root bucket. Directory keys now start with ./ and the report is versioned.

Keep reports outside the scan

A previous report must not inflate the next scan. The CLI checks the output path before scanning and refuses existing files.

Make exclusions explicit

Exact relative paths skip the selected subtree. Similar names and nested directories remain separate choices.

Report partial observations

Readable files remain in the report when a path fails; error types and completeness are visible beside the totals.

Run locally

Python 3.10+ and the standard library. Start with the synthetic example, then choose your own directory and an existing output folder outside it.

python examples/make_sample.py
python -m unittest discover -s tests -v

python scripts/inventory.py --root "D:\ExampleProject" --output "D:\Reports\inventory.json" --exclude node_modules --large-mib 32

Reading the size totals

Logical length is not allocated disk space. Hardlinks count per path, exclusions are omitted, and a changing filesystem is not an atomic snapshot. Reports may contain private names and should be reviewed before sharing.

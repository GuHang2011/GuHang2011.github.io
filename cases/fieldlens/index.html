禾镜 FieldLens

一个用于作物图片检测与结果复核的工作台。可选择图片或调用摄像头拍照，按使用环境切换配色；支持逐区域复核、记录对照、巡检报告和通用 AI 辅助。

公开页面是交互演示，示例图片和检测框均为预设数据。真实 YOLO 推理需要在本地配置有授权的目标检测权重；本项目没有发布模型精度或病害确诊结论。

v1.8：AI 助手有了独立入口

  • 操作答疑：查找拍照、检测、复核、报告和平台接入的内置说明，直接跳转到相关页面。
  • 本地记录整理：按选中快照生成复核清单，或汇总近 7 天巡检概况，可导出 TXT。明确标注为本地规则，未调用语言模型。
  • 平台 AI：配置服务端 DeepSeek 等兼容接口后，可对记录提问；保留发送预览、取消等待和文字导出。切换记录或离页后，旧回答不会覆盖新内容。

公开演示可使用操作帮助和本地整理，不提供公共平台密钥。真实问答需部署后端并配置自己的平台；回答不会自动修改记录。

v1.6：换肤与摄像头拍照

  • 可视换肤：预览经典浅色、田野青绿、深色、暖砂，或跟随系统深浅设置。即时切换、记住偏好，可恢复默认；图片和输入草稿保留。
  • 摄像头拍照：开启预览、选择摄像头、拍照后确认或重拍。确认照片后进入工作台，沿用原有 YOLO 检测流程。
  • 设备回退：权限、占用和断开有明确提示；可改用系统相机或已有照片。拍照完成或关闭窗口后释放摄像头。

取景不自动上传，也不请求麦克风。公开页面可拍照预览，真实识别仍需本地模型。摄像头需要 HTTPS 或 localhost 及授权；不同手机浏览器支持情况有差异。

从用户问题到具体修复

用户会遇到的问题改进后的操作
现场采样需要先退出网页去拍照。增加摄像头取景、重拍和确认入口，确认后沿用检测工作台；支持系统相机回退。
夜间或不同投屏环境想换配色。提供四种配色和跟随系统，可视预览、恢复默认，保留图片和输入草稿。
在线页面能直接识别自己的图片吗？在操作前显示能力说明。在线版禁用真实检测入口，并提供 Windows、macOS / Linux 本地运行步骤。
图片里的检测区域太小，看不清楚。新增 50%–300% 相对缩放与适应窗口，检测框同步缩放；可隐藏框查看原图。
JSON 不便于给同事看，也不便于整理。可导出带标注的 PNG、CSV 表格和 JSON。PNG、CSV 明确保留“演示”来源，CSV 可按筛选结果导出。
重复点击保存，出现多条相同记录。同一次检测、同一阈值重复保存会被阻止；修改备注更新原记录。
找不到某个样本，也不知道哪些还没看。按图片名、类别、备注搜索，结合检测来源和复核状态筛选，支持分页与真实记录统计。
记录只有数字，没法写复核意见。详情展示类别、置信度和归一化坐标，可添加备注、标记已查看。原始图片不会写入浏览器记录。
只想删错的一条记录，却只能全部清空。新增单条删除和确认提示；清空全部保留为独立操作。
选错图片或检测等太久，怎么退出？可清除当前图片、取消等待。防止旧图片读取完成后覆盖新选择；取消后不生成成功记录。

v1.2：把一次检测接到后续巡检

  • 样本与批次：填写样本编号、作物、地块、采集时间与巡检批次，按日期和地块组合查找。
  • 复查待办：安排补拍、结果存疑等任务，填写计划日期和处理说明，关联后续检测；已查看与已完成分别记录。
  • 完整备份：导出全部记录并恢复，导入前检查重复和冲突；默认保留旧记录，只有明确选择才覆盖。
  • 容量保护：达到 30 条后停止新增，保留当前结果供导出，不自动删除历史。

提醒仅在打开站点时显示，不提供浏览器关闭后的推送。备份不含原图或模型权重。

v1.3：复核意见可以落到具体区域

  • 逐区域复核：标记待确认、保留或疑似误检，填写原因，原始检测框与置信度不变。
  • 两次记录对比：查看样本信息、位置示意与数量；模型、阈值、来源不一致时给出提示，不按框数判断病情。
  • 巡检报告：按当前筛选结果生成报告，支持学院或课程名称、演示记录分组和浏览器打印为 PDF。
  • AI 平台接口：保留 YOLO，增加服务端兼容 Chat Completions 的文字接口，可配置 DeepSeek 等；发送前预览，回答不会自动修改记录。

AI 密钥仅放在服务端。公开静态页面保留接入入口与文档，不调用真实平台；本次仅用模拟响应验证接口，未使用付费密钥评估效果。记录对比不包含已存原图。

实现与验证

  • 前端：原生 ES Modules、Vite、Canvas；对照 Element 官网色彩、导航、表格和表单规范，采用浅色分组侧栏、标准表单、桌面表格与手机记录卡片；支持宽屏三列布局及详情分区。
  • 本地服务：Flask、Pillow、可选 Ultralytics YOLO；SQLite 保存账号与会话。上传图片在内存中处理，不随仓库分发模型权重。
  • 记录：浏览器本地存储，最多 30 条，满额停止新增；完整 JSON 备份可手动跨设备恢复，不包含原图。
  • 验证：34 项前端逻辑测试、21 项后端接口测试和浏览器流程检查；覆盖 360–2560px 布局、导出、筛选、复核、删除与失败状态。
  • 实际模型精度、不同设备推理速度和田间效果尚未评估。

FieldLens: a user-centered inspection workflow

Review crop images, zoom into detection regions, export annotated PNG/CSV/JSON reports, and manage sample batches, plots and follow-up tasks. Complete JSON backups support previewed imports with explicit conflict choices; full storage never evicts older records. Version 1.8 adds a dedicated assistant with built-in usage search, local review checklists and a compatible provider interface. Local outputs are explicitly rule-based, and the public demo does not call a model. Version 1.7 adds a no-login online demo with twelve preset cases, an isolated tab session and reset/share controls. Visitors can follow detection, review, reports and dashboard workflows without changing personal records. Version 1.6 adds a visual skin chooser, warm-sand and system appearance, and camera preview with retake and photo confirmation. Capture was tested using synthetic media; physical cameras and mobile devices have not been tested. Photos are not uploaded automatically. Version 1.5 adds classic, field-green and dark themes, adjustable viewing sizes and a focused two-screen presentation with pausable rotation. Version 1.4 adds administrator-created accounts, a fullscreen dashboard and a replayable guide. Real authentication needs a deployed backend; the public site does not collect credentials, and inspection records remain browser-local. Version 1.3.1 refines the interface with tabbed details and mobile record cards. Version 1.3 adds region-level manual reviews, record comparison, printable reports and a server-side compatible AI adapter. The public demo uses synthetic artwork and preset annotations; it does not call an AI provider. Real YOLO inference requires an authorized local model; no crop-model accuracy claims are made.

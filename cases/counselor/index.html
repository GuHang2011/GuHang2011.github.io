01 / WORKFLOW

Progress and approval are separate states

A task at 100% progress is not automatically an accepted task.

Campus tasks combine multiple participants, materials, deadlines and review. The implementation tracks individual progress, start and due dates, submissions, acceptance, return comments, extensions and cancellations. The dashboard separates current work from future arrangements; review-required tasks count as complete only after approval.

02 / SYSTEM BOUNDARIES

Role permissions and retries

01

Visible selection stays current

Changing a filter clears selected tasks that are no longer visible, reducing accidental bulk review of hidden items.

02

Access follows the resource

The server scopes access by person, class or college. Student-care text has a separate visibility boundary; contacts, chat sessions and attachments are checked independently.

03

Retry is part of the contract

The browser provides weak-network retry and submission feedback. The server handles repeated requests and content conflicts, so an uncertain response does not justify blind duplication.

03 / RELEASE VERIFICATION

Bind acceptance to the artifacts

The release process records SHA-256 digests of the backend program, production frontend directory and browser report. It recalculates them before packaging. Changed artifacts, incomplete restart evidence, browser failures or skipped checks block packaging. Copied artifacts are checked again afterward, with a package manifest and ZIP digest.

Remaining deployment work

Current design assumes a single backend instance. Local records do not cover target MySQL, a production Linux service, certificates, real roster migration or external model quality. Runtime and dependency upgrades require assessment.

A research question to test

Do business states, page actions and server permissions remain consistent? Can binding reports to artifacts reduce version-mixing errors? These questions need a defined fault model and controlled comparisons before claiming user-efficiency improvements.

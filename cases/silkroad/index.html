From entry to fulfillment

Actual frontend views with synthetic teaching content. Login fields are empty.

01 / MARKETING

Draft, review, publish

Chinese, English and Kazakh drafts connect a product to its target market. Editing an approved asset returns it to draft, so customer-facing content passes review again.

02 / ORDERS

A ledger beyond the overview

Administrators search and page through order history by number, SKU, status or destination. Details and A4 documents read the saved item and price snapshots, rather than recalculating from current product data.

03 / FULFILLMENT

Every step leaves an event

The task card traces inspection, locating, picking and dispatch as ordered status changes. Its event history records the teaching simulation; failed tasks can be retried, with simulation and device event sources kept distinct.

03 / ENGINEERING DECISIONS

Make invalid actions explicit

01 / STATE

Quality gates before dispatch

Only a passed quality check permits task creation. Task events must follow QUEUED → INSPECTING → LOCATING → PICKING → COMPLETED. A failure records its reason; retry returns the task to the queue.

02 / ACCESS

The same scope on every route

Customers read their own orders, tasks and after-sales records; administrators read within their college. Historical details and print routes recheck visibility. Model context excludes recipient names and addresses.

03 / RETRY

A retry must mean the same request

Order request IDs are scoped to the user; reusing an ID with different content is rejected. Transactions reserve stock at server prices, cancellation returns stock once, and event IDs prevent duplicate task advancement.

05 / SCOPE & PROVENANCE

What this case represents

A teaching system

The project adapts an existing Vue 3, Spring Boot and MySQL application, reusing its account and college-isolation foundation. Screenshots show the actual frontend with synthetic teaching data. Payments and logistics are simulations; no production deployment or physical robot operation is claimed. Structured service retrieval is not vector RAG, and media tools prepare prompts and storyboards rather than generate media.

Design and assets

The frontend reuses the MIT-licensed vue-next-admin template.

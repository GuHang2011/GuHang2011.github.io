READING MAP / WHAT TO INSPECT

The order is a state machine

01 / FLOW

Each step has an exit rule

Customer lookup, service selection and order review are separate states, so incomplete input cannot silently skip ahead.

02 / REVIEW

Show the generated order

The review step makes the customer, service, address and synthetic order ID visible before commit.

03 / CONFLICT

Conflict recovery is explicit

The duplicate-order switch exposes a conflict message and keeps the user in the review state for a deliberate retry.

# Reliability Gate Lab

A synthetic, dependency-free teaching demo for the proposed evidence-aware multimodal decision protocol. Adjust quality, calibrated confidence, disagreement and available modalities to see an automatic-output, review or insufficient-evidence state.

The thresholds are illustrative. This page does not train a model or report emotion-recognition performance. See the [research question](../../research/statement.html#rq-decision), the [learning note](../../notebook/multimodal-gates.html) and the [public protocol](../../research/protocol.md).

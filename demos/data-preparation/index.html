    01 / NOTES & EVIDENCE

    A small dataset, explicit decisions

    Quality before scale

    Zero is an observed value; a missing amount is unknown. Strict UTC validation rejects impossible calendar dates. Equal IDs with different business fields require a stated conflict policy. Amounts are aggregated as integer cents.

    Original Spark & preparation notes →

    Verified scope

    A new browser experiment using synthetic events and PapaParse. The core has automated checks for zeros, calendar boundaries, conflict policies, reconciliation and idempotence. It does not run Spark or benchmark distributed processing.

    Read the automated checks →

    Data and source boundary

    Prepared from local data engineering study topics. No textbook pages, examination questions, private records or production data are included. The sample uses a 2000–2099 UTC date contract and two-decimal amounts within ±1,000,000.

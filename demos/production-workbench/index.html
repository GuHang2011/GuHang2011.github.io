READING MAP / WHAT TO INSPECT

Three decisions behind this interface

01 / INPUT

Validate at the edge

Machine, quantity and batch reference have visible constraints before submission. Invalid input keeps the user in context.

02 / STATE

Make progress readable

The step list, progress bar and status chip move together, so a reviewer can see which state the interface claims to be in.

03 / RECOVERY

Failure is a designed state

The one-shot failure switch exposes a retry path instead of hiding an error behind a permanent spinner.

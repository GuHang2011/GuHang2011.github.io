What this demonstrates

01

Union types make states visible

The React source models draft, review, changes and approved as a finite workflow. Invalid transitions are rejected at the reducer boundary.

02

Async actions need an owner

A request id and version check prevent a late response from overwriting a newer task state. The preview exposes the conflict path instead of hiding it.

03

A demo carries its limits

There is no backend, authentication or production SLA here. The value is the readable contract, keyboard path and testable error state.

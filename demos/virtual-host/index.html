完整实现说明 ↗
01

一个时间源，多个界面状态

音频播放位置驱动角色动作、章节与字幕。暂停时动画一起停止，切换角色保留进度；语速调整继续沿用同一时间源。

02

操作反馈与失败恢复

界面使用 Vue 3 与 Element Plus。Mao 加载失败时可重试或切换小林；播放视频会暂停讲解，避免声音重叠。

03

公开素材与能力范围

Mao 是 Live2D 官方示例角色；配音为通用合成声音，商品为教学样例。这是前端集成演示，不是写实模型推理或直播实录。

# 从一次预测到可信评估：学习笔记

**性质：原创合成教学示例与阅读总结。** 没有训练模型，也没有复现或验证任何论文结论。

## 1. 先分清要平均什么

假设两个独立训练运行输出分数 `p_A`、`p_B`，标签为 `y`，评估函数为 `M`。

- **多次运行的指标摘要**：分别计算 `M(y, p_A)`、`M(y, p_B)`，再汇总均值、标准差与每次运行结果。它回答训练随机性的稳定性问题。
- **预测集成**：先计算 `p_mean = (p_A + p_B) / 2`，再计算 `M(y, p_mean)`。它回答组合预测后的表现问题。

`mean(M(y, p_i))` 通常不等于 `M(y, mean(p_i))`。本页两条样本在阈值 `0.5` 下分别得到准确率均值 `0.5` 与集成准确率 `1.0`；该例仅证明运算不同，不证明集成必然有效。

做预测集成之前，应确认样本 ID、行顺序、标签定义、正类含义和分数尺度一致。不同模型的未校准分数直接平均可能不合理。

## 2. 随机种子与集成解决不同问题

固定种子可以帮助复现数据划分、初始化和采样过程，但不能保证所有设备、并行计算及库版本完全相同。记录环境、数据哈希、配置、代码版本和划分 ID 比只写一个种子更完整。

不同种子运行的均值与标准差属于重复实验的稳定性报告。将不同运行的预测平均则改变了最终预测器，应该单独列为集成结果，并说明成员数量、检查点选择与融合规则。

本示例输入全部固定，没有随机训练或采样，不需要用一个“种子”装饰复现声明。生成文件记录输入 SHA-256 与 scikit-learn 版本。

## 3. 阈值会改变分类，排序指标观察另一件事

| 指标 | 观察对象 | 此演示的约定 |
|---|---|---|
| Accuracy | 正确预测占比 | 由当前阈值生成硬标签 |
| Precision | 预测正类中有多少真实正类 | 无预测正类时记 0 |
| Recall | 真实正类被发现的比例 | 正类为标签 1 |
| F1 | Precision 与 Recall 的调和平均 | `zero_division=0` |
| ROC AUC | 不同正负样本的排序能力 | scikit-learn 全部分数边界 |
| AP | 召回增量加权的 precision 汇总 | 不是梯形 PR 积分 |

改变分类阈值时，TP / FP / FN / TN、Accuracy、Precision、Recall 和 F1 都可能变化。固定分数的 ROC AUC 与 AP 不随选择的单一阈值变化。

PR 曲线按 scikit-learn 约定保留末端 `(recall=0, precision=1)`。无正类预测时，本页当前阈值圆点与指标表采用 `zero_division=0`，精确率为 0。两者采用不同的边界约定，不能把这个差异当作计算错误。

类别不平衡时，较高 Accuracy 可能来自总是预测多数类。应同时查看类比例、混淆矩阵、召回率与 PR，且结合任务的错误成本。合成平衡数据不覆盖这类部署风险。

## 4. 检查点、阈值与数据分离

真实流程可以写成：训练集训练 → 验证集选检查点与阈值 → 固定方案 → 独立测试集一次评估。

“最佳检查点”需要写清 **用哪个验证指标、哪个方向、在哪个划分上选择**。不能用测试集选择最佳 epoch，再把同一测试集分数作为独立泛化证据。

本页阈值滑块用于观察指标关系，不执行优化，也不推荐将合成样本上的最高值作为模型成果。后续真正开展实验时，可补充固定划分、运行日志、每次种子结果、置信区间、消融设置与失败样本分析。

## 5. 实现中的三个可检查点

1. 对 `score == threshold` 明确采用 `>=`，避免展示标签与后端统计不一致。
2. 对无正类预测的情况明确零分母策略，不把 NaN 混入展示或导出。
3. 保留逐样本预测和混淆计数，让指标可以被追溯，而不是只展示一个漂亮的汇总值。

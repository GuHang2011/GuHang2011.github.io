Evaluation boundary

This is an original teaching demo using fixed synthetic scores. No model was trained here, and these values are not research results. Metric calculations use scikit-learn 1.7.2 with zero_division=0.

Threshold exploration is descriptive. In a real experiment, choose thresholds and checkpoints on validation data, freeze the choices, then evaluate once on held-out test data. Prediction averaging assumes aligned sample IDs and the same positive class.

The connection between these changes

A path tells a script where to run. A token tells a response which session it belongs to. A generation tells an upload whether it still owns the page. A digest tells a release checker whether the files changed. These mechanisms answer different questions, but all require making an implicit assumption explicit.

A useful review question is: which assumption becomes false after an account switch, a directory move or a new build? It is easier to design a check after naming the specific failure.
